# 01: Setup do Projeto Next.js, Banco SQLite e Dashboard de Produtos

**What to build:** An operational Next.js application with TypeScript and Tailwind CSS, SQLite database schema for Shopee products, and an interactive dashboard interface displaying product cards with image, price, sales count, external Shopee link, and status switcher (`Pendente`, `Vídeo Publicado`, `Descartado`).

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Next.js (App Router) project initialized and configured with Tailwind CSS and Lucide icons
- [x] SQLite database setup with Prisma ORM model for `Product`
- [x] API routes to list products and update product status
- [x] Responsive dashboard UI showing products grid, status filter tabs, and action buttons
- [x] Status update functionality working dynamically without full page reload
